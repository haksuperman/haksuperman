#### ☁️ Cloud & Infrastructure
OCI를 중심으로 인프라와 네트워크·보안을 구성하고 운영합니다. AWS와 Kubernetes도 실습하며 클라우드 환경에 대한 이해를 넓히고 있습니다.

#### ⚙️ Automation
반복되는 운영 작업을 Python과 OCI SDK로 자동화합니다. 리소스 현황을 정리하고 테스트 환경을 관리하는 등, 실제 업무에 활용할 수 있는 도구를 만듭니다.

#### 📝 Learn & Share
새로운 구성은 테스트 환경에서 직접 확인하고, 장애는 재현하며 원인을 찾아갑니다. 그 과정에서 배운 내용과 해결 방법을 기술 문서와 블로그에 기록하고 공유합니다.
