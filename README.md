클라우드 인프라 운영 경험을 바탕으로, 반복되는 일을 자동화하고 안정적인 운영 환경을 만들어가는 **DevOps Engineer 박학수**입니다.

클라우드 인프라와 Kubernetes를 운영하고, Python과 AI 개발 도구를 활용해 업무에 필요한 도구를 만듭니다. Terraform 기반 IaC를 실습하며, 인프라 구성과 배포를 코드로 관리하는 방식에 관심을 넓혀가고 있습니다.

새로운 구성은 직접 확인하고, 문제가 생기면 재현하며 원인을 찾아갑니다. 그 과정에서 배운 내용과 해결 방법을 Engineering Wiki와 블로그에 기록하고 공유합니다.
