안녕하세요! 클라우드 인프라 운영 경험을 바탕으로 자동화와 안정적인 운영 환경을 만들어가는 **DevOps Engineer 박학수**입니다.  
반복 작업을 코드로 옮기고, 새로운 구성은 직접 검증하며, 배운 내용은 기록하고 공유합니다. 🚀

#### ☁️ On the infrastructure side,
클라우드 인프라와 네트워크·보안을 구축하고 운영합니다. Kubernetes 클러스터 구축과 관리형 Kubernetes의 버전 업그레이드, Node Cycling 등 유지보수를 수행하며 운영 중 발생하는 문제의 원인을 분석합니다.

#### ⚙️ On the automation side,
Python과 클라우드 SDK로 리소스 현황 정리와 테스트 환경 관리에 필요한 도구를 만듭니다. Claude Code와 Codex를 개발에 활용하고, 개인 AI Agent 시스템도 구축하고 운영합니다.

#### 🌱 On the DevOps side,
Terraform 기반 IaC와 CI/CD를 실습하며, 인프라 구성부터 애플리케이션 배포까지 코드로 관리하는 방식에 관심을 넓혀가고 있습니다. 운영에서 쌓은 경험을 반복 가능한 자동화로 연결하고자 합니다.

#### 📝 On the sharing side,
직접 검증한 구성과 장애 대응 경험을 Confluence 기반 Engineering Wiki와 Knowledge Base로 정리합니다. 배운 내용과 문제 해결 과정은 블로그에도 기록하며 팀이 다시 활용할 수 있는 기술 문서를 만듭니다.
